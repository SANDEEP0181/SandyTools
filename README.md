# SandyTools

Free, fast, browser-first online utilities for everyday work.

## Highlights
- Percentage, age, EMI, GST, SIP and discount calculators
- YouTube title, description and hashtag helpers
- Word and character counters
- Case, date, time and unit tools
- Password generator
- Image compression and resizing
- QR code generation
- PDF merging
- Responsive card-based interface
- SEO pages, sitemap and robots.txt

## Privacy-first approach
Most calculations and file operations are designed to run in the browser. Third-party services are used only where the site explicitly needs them.

## Project structure
- index.html — main tools page
- style.css — responsive UI
- script.js — tool logic
- about.html / contact.html / privacy.html / terms.html — site pages
- sitemap.xml / robots.txt — search-engine configuration

## Development
No build system is required. Open index.html locally or serve the folder with a simple static web server.

## Quality goals
Accessibility, mobile usability, fast loading, clear validation, and minimal dependencies are prioritized.

## Disclaimer
Tool results are informational. Independently verify important financial, legal, medical, or business calculations before relying on them.
