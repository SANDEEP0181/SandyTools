# Security Policy

SandyTools is a browser-first collection of free utility tools.

## Security priorities
- Never commit API keys, passwords, wallet seed phrases, private keys, or other credentials.
- Browser-side tools should not require server secrets.
- Treat third-party services as external dependencies and document them.
- Test security fixes before release.

## Reporting
Use GitHub's private security reporting mechanism when available. Do not publish credentials, private data, or working exploit details in a public issue.
